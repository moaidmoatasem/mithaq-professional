# Starlight Documentation Site Setup Plan for Cherenkov Security

## Goal
Set up a documentation website for https://cherenkov-security.com/ using the Starlight framework.

## Prerequisites
- Node.js 18.17.1 or 20.3.0+
- Astro 6.0.0 (Starlight v0.38.x requires Astro v6)
- Package manager (npm, pnpm, or yarn)

## Plan Overview
1. Initialize a new Starlight project
2. Configure Starlight for Cherenkov Security branding
3. Set up content structure
4. Create initial documentation content
5. Customize navigation and styling
6. Test and build the site

## Detailed Steps

### 1. Project Initialization
- Create a new directory for the documentation site (e.g., `cherno-docs`)
- Run: `npm create astro@latest -- --template starlight`
- This will:
  - Set up a new Astro project with Starlight template
  - Install all required dependencies
  - Create basic project structure

### 2. Starlight Configuration
- Edit `astro.config.mjs` to configure Starlight:
  ```js
  import { defineConfig } from 'astro/config';
  import starlight from '@astrojs/starlight';

  export default defineConfig({
    integrations: [
      starlight({
        title: 'Cherenkov Security Documentation',
        logo: {
          src: '/src/assets/logo.svg', // To be added
          alt: 'Cherenkov Security'
        },
        // Additional configuration as needed
      }),
    ],
  });
  ```

### 3. Content Collection Setup
- Ensure `src/content.config.ts` exists with:
  ```ts
  import { defineCollection } from 'astro:content';
  import { docsLoader } from '@astrojs/starlight/loaders';
  import { docsSchema } from '@astrojs/starlight/schema';

  export const collections = {
    docs: defineCollection({
      loader: docsLoader(),
      schema: docsSchema(),
    }),
  };
  ```

### 4. Content Creation
- Create documentation structure in `src/content/docs/`:
  - `index.md` - Homepage/overview
  - `getting-started/` - Installation and setup guides
  - `architecture/` - System architecture documentation
  - `usage/` - How to use the platform
  - `api/` - API reference (if applicable)
  - `contributing/` - Developer contribution guidelines
- Each markdown file should include frontmatter:
  ```markdown
  ---
  title: Page Title
  description: Page description
  layout: doc
  sidebar:
    order: 1
  ---
  ```

### 5. Navigation and UI Customization
- Configure sidebar in `astro.config.mjs`:
  ```js
  starlight({
    // ... other options
    sidebar: [
      {
        label: 'Getting Started',
        items: [
          { label: 'Introduction', link: '/getting-started/' },
          { label: 'Installation', link: '/getting-started/installation' },
          // ... more items
        ]
      },
      // ... more sections
    ],
    // Optional: custom CSS for branding
    customCss: ['./src/styles/custom.css']
  });
  ```

### 6. Development and Testing
- Run development server: `npm run dev`
- Verify site loads correctly at `http://localhost:4321`
- Check responsive design, dark mode, and navigation
- Run build: `npm run build`
- Preview build: `npm run preview`

### 7. Deployment Preparation
- The built site will be in the `dist/` directory
- Can be deployed to any static hosting service (Netlify, Vercel, GitHub Pages, etc.)
- Ensure base URL is configured if deploying to a subdirectory

## Files to Create/Modify
- `astro.config.mjs` - Starlight integration and site configuration
- `src/content.config.ts` - Content collection configuration
- `src/content/docs/` directory - All documentation content
- `src/assets/` - Logo and other static assets
- `src/styles/custom.css` - Optional custom styling
